# Kitchen-Equipment-Sales-Performance-Dashboard
This project aims to transform raw sales transaction data into an interactive Looker Studio dashboard to help management monitor sales revenue, assess business performance accurately, and drive data-informed decision-making.

## Insight:
- Cleaned and structured raw sales transaction data (handling missing values, formatting date structures, and standardizing product/city names).
- Calculated key sales metrics, including Total Revenue, Total Orders, Order Completion Rate, and revenue breakdowns by product, category, and city.
- Designed and developed an interactive dashboard in Looker Studio using trend lines, doughnut charts, and bar graphs to display sales distribution clearly.

## Outcome: 
Successfully built and deployed an interactive Business Intelligence dashboard in Looker Studio to streamline business performance monitoring and track key sales KPIs in real time.
